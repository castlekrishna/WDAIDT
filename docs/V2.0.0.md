# WDAIDT V2.0.0 — Self-Contained Chrome Extension Release Notes

**Release Version:** V2.0.0  
**Release Date:** October 25, 2026  
**Milestone Focus:** Self-Contained Chrome Extension, Direct Gemini API Integration, In-Panel Settings & Secure Key Storage, Zero-Network Mock Mode, and Full Backend Independence  

---

## 1. Executive Summary

**Why Did AI Do That? (WDAIDT) V2.0.0** transforms the tool into a completely self-contained Chrome Manifest V3 browser extension. 

In V1.0.0, users were required to clone the repository, install Python 3.10+, set up a virtual environment, install dependencies, and run a local FastAPI server on `http://localhost:8000`.

With V2.0.0:
- **No Python or Terminal Required**: End users load the extension directly into Chrome and begin analyzing immediately.
- **Direct Gemini API Integration**: Calls Google's Generative Language API directly over HTTPS using a user-provided Gemini API key.
- **In-Extension Settings**: API keys and preferences are managed directly through a settings modal inside the side panel and persisted securely in `chrome.storage.local`.
- **Built-in Mock Mode**: Provides zero-network, instant analysis fixtures for users without an API key or when offline.
- **Obsidian Dark Aesthetic Preserved**: Retains the signature pitch-black UI (`#000000`), subtle cards (`#111111`), borders (`#303030`), and accessible status indicators.
- **Historical V1 Reference Available**: The original Python/FastAPI local server has been retired from the main branch and remains preserved under historical Git release tags (`v1.0.0`) for architecture reference.

## 3. Key Enhancements in V2.0.0

1. **Direct Gemini REST Client (`extension/src/shared/gemini-client.js`)**:
   - Uses official REST endpoint: `https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`.
   - Transmits API key securely via `x-goog-api-key` HTTP header (never in URL parameters or logs).
   - Default model: `gemini-3.5-flash-lite` with automatic fallback to `gemini-flash-latest` and `gemini-3.8-flash`.
   - Handles HTTP 404 (retired models) and 503 (high demand) with graceful candidate fallback.
   - Enforces a 2-attempt validation recovery loop for malformed JSON output.

2. **In-Panel Settings & Local Persistence (`extension/src/sidepanel/`)**:
   - Gear icon opens the slide-out settings drawer.
   - Password-masked API key input with show/hide toggle and one-click clear.
   - Status indicators dynamically update between `Mode: Mock (offline)`, `Gemini: Ready`, and `Gemini: API Key required`.
   - All settings persist locally via `chrome.storage.local`.

3. **Zero-Setup Mock Mode (`extension/src/shared/mock-analyzer.js`)**:
   - Fully deterministic offline analysis based on conversation properties (factual vs. code vs. reasoning).
   - Generates valid 9-block document structures conforming to the strict WDAIDT schema.
