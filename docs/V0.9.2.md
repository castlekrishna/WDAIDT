## 3. Engineering & Usability Audit

### Chrome Extension (Manifest V3)
- Validated `extension/manifest.json`: required permissions (`sidePanel`, `storage`, `activeTab`, `scripting`), host permissions (`chatgpt.com`, `chat.openai.com`), action icon, and side panel declaration.
- Verified 6-tier DOM extraction hierarchy in `extension/src/content/chatgpt.js` piercing open shadow roots and excluding toolbars, live announcers, surveys, and disclaimers.
- Confirmed stream watcher detects finished assistant responses with 2-second debounce for Auto Analyze.
- Verified pure DOM rendering using `textContent` for all 9 block types; zero `innerHTML` usage eliminates XSS vulnerabilities.
- Verified keyboard accessibility: high-contrast focus rings (`var(--focus-ring)`), `Enter`/`Space` activation, and accessible `Escape` key dismissal for settings.

### FastAPI Backend
- Verified `GET /health` (`{"status": "ok"}`) and `POST /analyze`.
- Confirmed Pydantic v2 validation enforcing limits: prompt ≤ 8k chars, response ≤ 20k chars, context ≤ 40k chars / 20 exchanges.
- Confirmed standardized error envelopes for HTTP 404, 405, 413, 422, 429, 502, 504.
- Confirmed zero-config hermetic Mock Mode (`MOCK_ANALYSIS=true`) and live Gemini API engine with 15s timeout and automatic retry.
- Verified CORS policy (`allow_origins=["*"]`, `allow_credentials=False`) enabling safe access from `chrome-extension://` callers.

## 4. Privacy, Security & Licensing Audit

- **No Secret Leaks**: Git log and file scans verified zero API keys or credentials committed to tracking.
- **Credential Protection**: `GEMINI_API_KEY` is loaded strictly on the backend from `backend/.env`. The extension never receives or stores API credentials.
- **Volatile Processing**: Prompts and responses are processed in ephemeral memory only; zero database tables or disk persistence.
- **Lengths-Only Logging**: Server and extension logs record character lengths and counts only—never conversation text.
- **Passive Data Isolation**: Untrusted conversation inputs are delimited within `<CURRENT_INTERACTION>` and `<CONVERSATION_HISTORY>` XML tags to guard against prompt injection.
- **MIT License**: Added official `LICENSE` file granting open-source permissions (Copyright 2026 Krishna Kumar, Lidiya).
